# Forge TDK

A Create T3-inspired landing page and starter surface for TDK CLI.

```bash
npm install
npm run dev
```

The site highlights the generated local stack story: Bun, Node.js, TypeScript, Docker, Traefik, Tilt, Prisma, PostgreSQL, NATS JetStream, Infisical, Playwright, C4 diagrams, and AGENTS.md.
